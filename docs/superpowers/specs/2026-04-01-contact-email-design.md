# Contact Form Email — Design Spec

**Date:** 2026-04-01
**Status:** Approved

## Overview

Complete the contact form email pipeline: add IP-based rate limiting via Upstash Redis, add `reply-to` header, and establish the DNS verification process for `maredatum.pt` on Resend.

## Architecture

```
Formulário (contact.tsx)
    ↓ Server Action
contactAction (contact.ts)
    ├── Validação Zod (existing)
    ├── Rate limiting por IP via Upstash Redis  ← new
    └── Envio via Resend
            ├── from: noreply@maredatum.pt  (after DNS verification)
            ├── to: geral@maredatum.pt
            ├── reply-to: email do contacto  ← new
            └── text: nome / empresa / assunto / mensagem (existing)

DNS (provided to Zé Luís Lucena)
    └── SPF + DKIM records for maredatum.pt in Resend
```

## Components

### 1. Rate Limiting (new)

- **Library:** `@upstash/ratelimit` + `@upstash/redis`
- **Strategy:** 3 submissions per IP per 60 minutes (sliding window)
- **IP extraction:** `x-forwarded-for` header (Vercel), fallback to `x-real-ip`
- **On limit exceeded:** return `{ status: "serverError", message: "Demasiadas tentativas. Por favor aguarde antes de tentar novamente." }`
- **Placement:** checked before Zod validation in `contactAction`

### 2. Reply-To Header (new)

Add `replyTo: email` to the `resend.emails.send()` call so replies from `geral@maredatum.pt` go directly to the contact.

### 3. Email Format

Plain text (approved). Template:

```
Nome: {nome}
Email: {email}
Empresa: {empresa}
Assunto: {assunto}

{mensagem}
```

Subject: `[MareDatum] Novo contacto: {assunto}` (existing)

### 4. Sender Domain (post-DNS)

- **Current (dev/staging):** `from: onboarding@resend.dev`
- **Production target:** `from: noreply@maredatum.pt`
- Change is made in `contact.ts` after DNS verification is confirmed in Resend dashboard.

## Environment Variables

| Variable | Where | Notes |
|----------|-------|-------|
| `RESEND_API_KEY` | `.env.local` + Vercel | Already set |
| `UPSTASH_REDIS_REST_URL` | `.env.local` + Vercel | From Upstash dashboard |
| `UPSTASH_REDIS_REST_TOKEN` | `.env.local` + Vercel | From Upstash dashboard |

## DNS Records (for Zé Luís Lucena)

Exact values are generated by Resend after adding `maredatum.pt` as a domain. Expected record types:

| Type | Name | Value |
|------|------|-------|
| TXT | `maredatum.pt` | `v=spf1 include:amazonses.com ~all` |
| CNAME | `resend._domainkey.maredatum.pt` | Provided by Resend |

MX records are not required (Resend only sends, does not receive).

## Deployment Checklist

1. Create Upstash account → create Redis database → copy REST URL and token
2. Add env vars to `.env.local` and Vercel dashboard
3. Implement rate limiting in `contact.ts`
4. Add `replyTo` to Resend call
5. Deploy to Vercel
6. Add `maredatum.pt` domain in Resend dashboard → copy DNS records
7. Send DNS records to Zé Luís Lucena
8. Wait for DNS propagation (15 min – 24 h)
9. Verify domain in Resend dashboard
10. Change `from` to `noreply@maredatum.pt` in `contact.ts` → redeploy

## Out of Scope

- HTML email templates (plain text approved)
- Honeypot / CAPTCHA (not requested)
- Email logging / storage
